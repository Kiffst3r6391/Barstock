BarStock — Simplified UI Concepts

A cleaner, task-first interface for managing bar stock day-to-day.

Design direction

These concepts keep the dark, utilitarian feel of a back-of-house tool but reduce clutter. Numbers are large and tabular. Status is encoded with colour chips. Each screen has one obvious primary action, and secondary tasks live behind clear navigation tabs. The palette uses deep navy/charcoal with a warm copper accent to feel bar-like without ornament.

What changes and why

Dashboard first. Open with what needs doing today, not a dense menu tree. Stats are big and tabular so staff can read them at a glance.

Units front-and-centre. Every input that needs bottles, cartons, or barrels tells you explicitly. Conversion results are shown right under the field so mistakes like “2 measures” instead of “2 bottles” are caught immediately.

Hard blocks for negative stock. The sales-upload preview now refuses to apply if an item would go negative, unless that item is explicitly allowed to go negative. This stops surprise stock outages.

One-page reconciliation. Instead of hunting through code, the reconciliation report gathers mapping gaps, order-sheet orphans, and negative trends in one place.
